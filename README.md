# NovaWiki — Frontend Assignment 5

Continue the Assignment 4 website with vanilla JavaScript.

## Run
Open `index.html` in your browser. No build tools or backend required. MDN links require internet.

## New features
- Dynamically rendered HTML/CSS/JavaScript article cards with category filters and a `switch` statement
- Read more details toggled with DOM attributes and animations
- Day/night theme and sound effects (sound starts off; click Sound off to enable)
- ArrowLeft / ArrowRight keyboard navigation in the header links
- Two-step learning form using a callback function
- Surprise me random article recommendation
- Objects and methods, arrays, `for...of`, `forEach`, `filter`, `find`

## Preserved Assignment 4 features
Registration validation, FAQ accordion, contact popup, background color changer, live clock. Forms are demos and do not send or store data.

## Submit
